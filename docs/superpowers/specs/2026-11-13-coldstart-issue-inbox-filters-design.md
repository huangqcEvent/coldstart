# ColdStart GitHub Issue 收件箱筛选增强设计

- 日期：2026-11-13
- 状态：已完成（阶段 18，2026-11-13）
- 关联：阶段实施计划仅保留在本地，不随开源仓库发布。

## 1. 目标

阶段 18 增强已有 GitHub Issue 需求入口，让人工可以从历史项目的大量 Issue 中更快找到可复用需求。具体包括：

- 按开放、已关闭或全部状态读取仓库 Issue。
- 在已读取快照内按编号、标题、标签或正文预览搜索。
- 按标签过滤。
- 只显示尚未导入为需求来源的 Issue。
- 人工导入已关闭 Issue，用于历史项目需求回溯。

本阶段仍然只提供桌面端人工操作，不自动生成蓝图、不自动领取任务，也不增加 MCP 工具。

## 2. 设计原则

1. 状态切换会重新执行一次 GitHub 只读列表请求；关键词、标签和导入状态只在本次快照内过滤。
2. 每个状态最多读取 50 条最近更新 Issue；不自动翻页，也不把筛选结果描述成仓库全量数据。
3. 已关闭 Issue 可以导入，但仍必须由人明确选择，且继续沿用来源哈希、锚点和重复导入保护。
4. 搜索只匹配编号、标题、标签和正文预览，不读取评论、附件或未加载的后续分页。
5. 不增加 MCP 工具，不升级 SQLite 架构，不创建、编辑、关闭、评论或分配 Issue。

## 3. 后端数据映射

### 3.1 状态参数

新增 `GitHubIssueListState`：

- `open`：`GET /repos/{owner}/{repository}/issues?state=open&sort=updated&direction=desc&per_page=100`
- `closed`：同一路径使用 `state=closed`
- `all`：同一路径使用 `state=all`

GitHub 返回结果中的 Pull Request 仍全部过滤；每个状态最多向桌面端返回 50 条，并在达到原始 100 条或超过展示上限时标记截断。

### 3.2 应用服务与桌面命令

- `GitHubIssueService::list_issues` 接收状态参数，并在列表视图中返回实际查询状态。
- Tauri 命令 `list_github_issues` 增加 `state` 参数，由 Rust 强类型反序列化。
- 单 Issue 导入命令保持不变；导入时仍重新读取最新快照，因此列表状态不会限制导入已关闭 Issue。
- 非 GitHub 仓库、凭据缺失、网络失败和非法响应继续返回既有稳定错误。

### 3.3 快照筛选

以下筛选完全在前端内存中执行：

- 关键词：对应 `#编号`、标题、标签合并文本和 360 字符正文预览。
- 标签：精确匹配当前快照出现过的标签。
- 仅未导入：与项目现有来源的 `importSource` 比较。

筛选条件不会触发额外网络请求，也不会修改数据库。清除筛选只重置界面输入。

## 4. 桌面交互

- 仓库、Issue 状态和“读取 Issue”构成读取区。
- 状态包括“开放”“已关闭”“全部”，默认开放。
- 读取成功后显示关键词、标签和“仅显示未导入”筛选。
- 摘要同时显示仓库、查询状态和匹配数量；有筛选时显示“匹配数/已读取数”。
- 没有匹配项时显示独立空态和“清除筛选”，不覆盖已读取快照。
- 已关闭 Issue 使用既有“已关闭”徽标，并允许人工导入。
- 切换仓库会清空快照和筛选；切换状态会清空旧快照，避免摘要与列表数据不一致。

## 5. 安全边界

- 仍只使用 GitHub REST 只读 GET，不新增写请求。
- Token 只进入 Rust HTTP Authorization 头，不进入前端、SQLite、事件、日志或项目文件。
- Issue 正文和标签只作为外部资料，不执行链接、命令或代码块。
- 不保存评论、原始 JSON、搜索关键词或筛选状态。
- 不增加 MCP 工具，MCP 总数仍为 11；Agent 不能读取、搜索或导入 Issue。

## 6. 明确不做

- 不调用 GitHub Search API，不提供跨仓库或跨状态全局搜索。
- 不自动翻页，不读取超过当前状态最近 50 条之外的 Issue。
- 不导入评论、附件、Projects 或 Milestones。
- 不自动刷新、后台轮询或订阅 Issue 变化。
- 不创建、编辑、关闭、评论、分配或批量导入 Issue。
- 不自动从 Issue 生成蓝图或计划。

## 7. 验收

- 应用测试覆盖状态透传、关闭 Issue 列表视图和只读请求边界。
- 前端测试覆盖状态切换、关键词、标签、仅未导入、清除筛选、空结果和已关闭 Issue 导入入口。
