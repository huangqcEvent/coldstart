# ColdStart MCP 项目记忆与上下文接力设计

- 日期：2026-11-13
- 状态：已完成（2026-11-13 通过全量验证）
- 适用阶段：阶段 11

## 1. 背景

阶段 9 已经把 SQLite 事件日志投影为桌面端只读的“项目记忆”，但 Codex 仍只能通过 `get_work_context` 看到当前任务及其直接依赖。新会话恢复、跨任务接力和历史失败原因仍然依赖人工复制，容易出现以下问题：

- 新会话不知道项目已经发布到哪个蓝图和计划版本。
- 后续任务看不到前序任务留下的已知问题、后续事项和失败原因。
- Codex 无法主动读取安全分页的项目记忆，只能等待人工描述历史。
- 项目级未决信息、阻塞和已确认事实没有统一的开工前入口。

本阶段把已有项目记忆扩展到 MCP，并增加只读的项目简报和任务接力视图。它不新增写入能力，也不启动 Agent。

## 2. 目标

1. 新增 `get_project_brief`：在领取任务前读取项目级安全简报。
2. 新增 `get_project_memory`：按现有游标分页读取安全事件投影。
3. 新增 `get_work_handoff`：在持有效租约时读取当前任务的前序工作、报告、已知问题、后续事项和阻塞。
4. 复用现有事件、计划、报告和项目事实，不建立第二套项目状态。
5. 所有响应保持有界、确定性、脱敏，不返回租约令牌、Secret、凭据引用、远程 URL 或本地绝对路径。
6. 保持“Codex 主动领取、ColdStart 不启动 Agent”的边界。

## 3. 非目标

- 不提供项目记忆写入、编辑、删除、重放或回滚。
- 不提供计划、仓库、凭据、Review 或审批的 MCP 写工具。
- 不实现向量检索、全文索引或云端记忆同步。
- 不自动合并、部署、打包、提审或发布 Release Tag。
- 不把完整报告、完整变更 diff 或原始事件 payload 返回给 Agent。

## 4. 核心决策

### 4.1 读模型，不是新事实来源

项目简报、项目记忆和任务接力都从现有 SQLite 表读取：

- `events`：项目记忆。
- `blueprint_revisions`、`plan_revisions`、`work_items`：项目与计划摘要。
- `work_reports`、`work_blockers`：任务结果、已知问题、后续事项和阻塞。
- `project_facts`、`info_requests`：已确认事实与未决信息。
- `repositories`：只返回逻辑键、名称和默认分支。

不新增数据库表，不复制计划或报告状态。

### 4.2 三种视图

| 工具 | 是否需要租约 | 用途 |
| --- | --- | --- |
| `get_project_brief` | 否 | 新会话开工前恢复项目全貌 |
| `get_project_memory` | 否 | 分页查看安全的历史变更 |
| `get_work_handoff` | 是 | 当前任务的前序工作和接力信息 |

`get_project_brief` 和 `get_project_memory` 只读，不改变工作项状态。`get_work_handoff` 必须先通过现有租约授权，授权失败不返回任何接力数据。

### 4.3 安全投影

响应只包含稳定 ID、状态、摘要和安全引用：

- 不返回原始 `payload_json`、租约 ID、租约令牌、`secretRef` 或 Secret。
- 不返回仓库远程 URL、本地路径或凭据引用。
- 报告中的自由文本统一去除控制字符，并按现有验证输出清洗器脱敏常见密钥形态。
- 授权类项目事实只显示“已登记”，不展开值；问题和值中出现 secret、password、token、密钥、密码、私钥等关键词时同样隐藏值。
- 单个文本字段截断到 500 字符；已知问题和后续事项每类最多 10 条；变更文件最多 30 条。

### 4.4 响应预算

固定上限保证 MCP 响应可预测：

- 项目简报：当前工作最多 10 条，最近完成最多 5 条，项目事实最多 20 条，未决信息最多 10 条，阻塞最多 10 条，最近记忆最多 10 条。
- 任务接力：相关任务最多 8 条，阻塞最多 10 条，未决信息最多 10 条。
- 项目记忆沿用 1 到 500 的分页限制，默认 100 条。

阶段 11 不引入新的 token 预算字段；更完整的上下文仍通过现有任务上下文和分页工具按需读取。

## 5. 应用层接口

```rust
pub struct ContextHandoffService;

impl ContextHandoffService {
    pub fn project_brief(
        &self,
        project_home: PathBuf,
    ) -> Result<ProjectBrief, AppError>;

    pub fn work_handoff(
        &self,
        project_home: PathBuf,
        work_item_id: WorkItemId,
        lease_token: String,
    ) -> Result<WorkHandoff, AppError>;
}
```

项目记忆继续由 `ProjectMemoryService::read` 提供；内部抽取一个接收已打开项目的只读分页函数，供项目简报复用。

## 6. MCP 工具

### 6.1 `get_project_brief`

参数为空对象。返回：

- 项目 ID、名称和生成时间。
- 当前已发布蓝图版本、目标、平台和模块数量。
- 当前已发布计划版本、任务总数和状态计数。
- 逻辑仓库键、名称和默认分支。
- 当前工作、最近完成工作及其最新报告摘要。
- 未解决阻塞、未决信息和最新项目事实。
- 最近 10 条非心跳项目记忆。

### 6.2 `get_project_memory`

参数：

```text
before_cursor?: positive integer
limit?: 1..=500
include_heartbeats?: boolean
```

返回现有 `ProjectMemoryPage` 安全投影，不增加原始事件字段。

### 6.3 `get_work_handoff`

参数：

```text
work_id
lease_token
```

先执行与 `get_work_context` 相同的租约授权，然后返回：

- 当前工作项和最新报告。
- 依赖任务、同模块任务和同仓库任务中的相关历史，最多 8 条。
- 当前任务及相关任务的未解决阻塞。
- 项目级未决信息。

相关任务按“直接依赖优先、更新时间倒序”排序。当前任务不重复出现在相关任务列表。

- README 更新 MCP 工具列表、推荐执行循环和能力边界。

## 8. 测试与验收

必须覆盖：

1. 项目简报包含当前蓝图、计划、工作项、报告、阻塞和记忆摘要。
2. 项目简报和接力响应不包含租约令牌、Secret、远程 URL、凭据引用或本地绝对路径。
3. 报告自由文本中的常见密钥形态被脱敏。
4. 授权类项目事实不返回值。
5. `get_project_memory` 支持游标和 limit，心跳默认隐藏。
6. `get_work_handoff` 缺少有效租约时拒绝返回数据。
7. 接力列表包含直接依赖优先的相关历史，并排除当前任务。
8. MCP `tools/list` 准确暴露 11 个工具，未知工具仍被拒绝。
9. Rust 全量格式、Clippy、测试和安装包构建通过。

## 9. 已知限制

- 项目简报基于当前已发布计划；更早计划的历史只通过项目记忆查看。
- 相关任务匹配限于依赖、模块和逻辑仓库，不做代码语义检索。
- 自由文本脱敏只能覆盖常见密钥形态，不能替代人工审查。
- 单机本地工具仍不防御拥有同一 OS 用户权限的恶意进程。
